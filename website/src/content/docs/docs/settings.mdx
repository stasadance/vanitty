Settings live in `~/.config/vanitty` (`%APPDATA%\Vanitty` on Windows, or `$XDG_CONFIG_HOME/vanitty`). Open them with **Settings > Open Settings** or <kbd>Ctrl</kbd>+<kbd>,</kbd> (<kbd>⌘</kbd>+<kbd>,</kbd> on macOS). They open in VS Code, VSCodium, Cursor or Zed when one is installed, and otherwise in your default app for JSON files.

`settings.json` takes the same options as Hyper's `config`, as JSON with comments. A JSON schema sits next to it, so VS Code autocompletes and validates it. Changes apply as soon as you save.

```jsonc
{
    "$schema": "./settings.schema.json",
    "fontSize": 13,
    "cursorShape": "BLOCK",
    "padding": "12px 14px",
    "themes": ["hyper-snazzy"],
}
```

## Profiles

A profile overrides any terminal option, such as the shell or colors. Pick one from the new-tab menu, or set `defaultProfile`.

On Windows, the shells Vanitty finds are listed there too: PowerShell, PowerShell 7, Command Prompt, Git Bash and each WSL distro. Set `defaultProfile` to one of their names to launch it by default.

```jsonc
"profiles": [
  { "name": "zsh", "config": { "shell": "/bin/zsh" } },
  { "name": "PowerShell", "config": { "shell": "pwsh.exe", "backgroundColor": "#012456" } }
]
```
